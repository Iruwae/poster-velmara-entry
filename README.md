# VELMARA — Isles of the Falling Sea

A travel poster for a place that does not exist, for the
[make.fun bounty](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

VELMARA is a chain of floating sky-islands where waterfalls pour off the
edges into a sea of golden cloud. One airship, one sunset, one promise:
come up here and watch the sea fall.

## Run

`main.ts` (Node 22) runs offline and writes the poster to `/output/entry.png`:

```sh
node main.ts
```

The artwork is produced at build time and shipped as `assets/poster.jpg`;
the program emits it deterministically, within the 1 MiB / 1024x1024 caps.
